# KAIST 별바라기

KAIST 동아리 별바라기 홈페이지

React로 만든 정적 웹사이트입니다. 방문자 화면과 관리자 화면이 있으며, 별도 백엔드 서버나 데이터베이스 없이 GitHub Pages와 GitHub Actions로 운영합니다.

### 관리자 페이지와 로그인

사이트 관리는 `/admin` 에서 가능합니다.

관리자페이지 로그인 비밀번호가 암호화된 파일은 `public/admin/accounts.json`에 저장되어 있습니다.
각 관리자는 별도의 무작위 salt와 IV를 가지며, 비밀번호로 PBKDF2-SHA256를 적용해 만든 키로 AES-256-GCM 암호문을 복호화합니다. 공개 파일에는 아이디·암호문·암호화 매개변수만 저장합니다. 비밀번호 원문이나 토큰 원문은 계정 파일·소스 코드·주소·로그·브라우저 저장소에 저장하지 않습니다. 
### 콘텐츠 JSON

`content`의 설정·소개·FAQ·전시·소식은 `.json`으로 관리합니다. 기존 `.txt` 파일은 JSON으로 전환했으며, 새로 추가할 때는 `추가용-템플릿`의 JSON을 사용하세요. 사진별 설명과 추가정보는 기존 `.md` 형식을 사용합니다.

- `설정/사이트정보.json`: 사이트 이름, SNS 링크, 창립연도, 모집 안내 등
- `설정/모집링크.json`: `{"url": "https://example.com/apply"}`. 빈 문자열이면 지원 버튼을 숨깁니다.
- `소개.json`, `설정/푸터.json`: `{"내용": "첫 문단\n\n둘째 문단"}`
- `FAQ.json`: `{"항목": [{"질문": "가입할 수 있나요?", "답변": "누구나 지원할 수 있습니다."}]}`
- `전시/<폴더>/전시정보.json`, `소식/<폴더>/소식.json`: 제목·소개·내용 등의 속성을 가진 객체

키 이름 목록으로 제한하지 않습니다. 사용자 지정 키와 문자열·숫자·불리언·배열·객체·null 값을 추가할 수 있고, 관리자에서 기존 항목을 수정해도 사용자 지정 값은 유지됩니다. 최상위 값은 JSON 객체이며, 화면에서 사용하는 제목·내용·URL 등의 기존 필드는 용도에 맞는 값이어야 합니다. 임의 키를 추가하는 것만으로 공개 화면에 새 항목이 자동 표시되지는 않습니다.

관리자의 기존 입력 화면은 해당 JSON을 저장합니다. **JSON 편집** 탭에서는 파일을 선택해 사용자 지정 키, FAQ, 사이트 설정까지 직접 편집할 수 있습니다. 유효한 JSON은 변경사항에 반영되며, 문법이나 기존 필드 형식에 오류가 있으면 저장이 차단됩니다. 마지막으로 **저장 및 배포**를 눌러 저장소에 반영합니다.
