# KAIST 별바라기

KAIST 동아리 별바라기 홈페이지

React로 만든 정적 웹사이트입니다. 방문자 화면과 관리자 화면이 있으며, 별도 백엔드 서버나 데이터베이스 없이 GitHub Pages와 GitHub Actions로 운영합니다.

### 관리자 페이지와 로그인

사이트 관리는 `/admin` 에서 가능합니다.

관리자페이지 로그인 비밀번호가 암호화된 파일은 `public/admin/accounts.json`에 저장되어 있습니다.
각 관리자는 별도의 무작위 salt와 IV를 가지며, 비밀번호로 PBKDF2-SHA256를 적용해 만든 키로 AES-256-GCM 암호문을 복호화합니다. 공개 파일에는 아이디·암호문·암호화 매개변수만 저장합니다. 비밀번호 원문이나 토큰 원문은 계정 파일·소스 코드·주소·로그·브라우저 저장소에 저장하지 않습니다. 

### 홈·푸터 편집

관리자 **홈 편집** 탭에서 첫 화면 안내 문구와 배경 사진, 활동사진 영역의 문구·링크·버튼 아이콘·배경 사진, 모집 배너 문구를 수정합니다. 문구는 `content/설정/홈.json`, 사진은 `content/홈/대표/`와 `content/홈/활동/`에 저장됩니다. 처음에는 기존 전시 사진을 사용하며, 홈 사진을 교체해도 전시 작품은 변경되지 않습니다.

**푸터 편집** 탭에서는 안내 문구와 링크를 관리합니다. 링크마다 표시 이름, 주소, 아이콘을 선택하고 추가·삭제할 수 있습니다. Instagram·YouTube·Facebook·이메일·일반 링크·아이콘 없음 중 선택할 수 있으며, 웹주소(http/https), 이메일(mailto), 전화(tel) 링크를 지원합니다. 설정은 `content/설정/푸터.json`에 저장되고, 링크를 모두 삭제하면 푸터 링크 영역이 비워집니다.

모든 변경은 상단 **저장 및 배포**를 눌러 반영합니다. 기존 JSON의 사용자 지정 속성은 편집 시 유지됩니다.
