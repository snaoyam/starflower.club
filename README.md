# KAIST 별바라기

KAIST 동아리 별바라기 홈페이지

React로 만든 정적 웹사이트입니다. 방문자 화면과 관리자 화면이 있으며, 별도 백엔드 서버나 데이터베이스 없이 GitHub Pages와 GitHub Actions로 운영합니다.

### 관리자 페이지와 로그인

사이트 관리는 `/admin` 에서 가능합니다.

관리자페이지 로그인 비밀번호가 암호화된 파일은 `public/admin/accounts.json`에 저장되어 있습니다.
각 관리자는 별도의 무작위 salt와 IV를 가지며, 비밀번호로 PBKDF2-SHA256를 적용해 만든 키로 AES-256-GCM 암호문을 복호화합니다. 공개 파일에는 아이디·암호문·암호화 매개변수만 저장합니다. 비밀번호 원문이나 토큰 원문은 계정 파일·소스 코드·주소·로그·브라우저 저장소에 저장하지 않습니다. 

### 콘텐츠 파일

`content/`와 `추가용-템플릿/`의 편집용 문서는 모두 `.md`입니다. 관리자에서 기존 입력 폼으로 수정하면 해당 Markdown 파일에 저장됩니다. 전시 정보는 `전시정보.md`, 소식 본문은 `소식.md`이며, 사진 설명도 기존 `.md` 형식을 사용합니다.

사진 설명처럼 `- 항목명: 값`으로 작성합니다. 임의의 항목 이름을 추가할 수 있으며, 여러 문단은 두 칸 들여써 이어 적습니다.

```md
- 제목: 밤하늘 관측회
- 내용: 첫 번째 문단입니다.

  두 번째 문단입니다.
- 사용자 지정 항목: 원하는 내용
```

FAQ의 `항목`과 하단영역의 `링크`처럼 여러 항목이 있는 값은 번호 목록으로, 각 항목의 속성은 하위 목록으로 작성합니다.

```md
- 항목
    1.
        - 질문: 장비가 필요한가요?
        - 답변: 동아리 장비를 사용할 수 있습니다.
```

숫자·`true`·`false`·`null`은 각각 해당 자료형으로 읽습니다. 이를 문자열로 저장하려면 `"1987"`, `"true"`처럼 큰따옴표로 감싸 주세요. 빈 배열은 `[]`, 빈 객체는 `{}`로 적습니다. 관리자는 이런 구분을 자동으로 처리하며 사용자 지정 항목도 보존합니다.

`package.json`, 계정 파일 `public/admin/accounts.json`, 사이트가 자동 생성하는 `public/data/*.json`은 프로그램용 데이터이므로 JSON 형식을 유지합니다.

본문·사진 설명·추가정보·안내 문구에 `[링크 표시](https://example.com/)`를 적으면 클릭 가능한 링크로 표시됩니다. 이 표준 Markdown 형식만 링크로 표시됩니다. 웹 링크는 새 탭에서 열리며, 주소는 `http://` 또는 `https://`로 시작해야 합니다.
